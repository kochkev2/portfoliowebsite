# Kevin Koch Portfolio

This repository contains my personal game design and development portfolio.

## About Me

I am a Games & Interactive Media and Spanish student at Michigan State University with interests in game design, pixel art, UI/UX design, and collaborative game development.

## Featured Projects

The portfolio currently showcases five projects:

- **Tinted Isle** — A strategic point-and-click gardening simulator focused on growing, discovering, and trading unique plants.
- **ConSwaption** — A physical memory card game about matching ingredients and crafting potions to defeat rival wizards.
- **Hive Blinds** — A strategic trick-taking card game built around influencing four competing hivemind races.
- **Shroom to Breathe** — A time-management and mental wellness app that rewards productivity with collectible mushroom creatures.
- **Fish Flop** — A 2.5D pixel-art puzzle platformer built around rotating fish tanks and changing perspective to solve puzzles.
